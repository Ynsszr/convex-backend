# Native SDK evidence

The 0.3.1 checks are recorded in
[implementation status](../../IMPLEMENTATION_STATUS.md). Supported behavior and
non-claims are in [CAPABILITIES](../../CAPABILITIES.md) and
[release scope](../../RELEASE_SCOPE.md). Earlier package-candidate totals are
historical.

One passing boundary does not settle the others. Source compilation,
package-only consumption, disposable backend checks, and an installed browser
check are separate. The release does not claim arbitrary hostile CLR hosting,
unmodified managed Convex Cloud support, unlimited cache history, hard cgroup
enforcement, or the complete optimistic JavaScript client ecosystem.
