# Managed source origin

This repository owns the Convex backend and the native .NET/F# SDK under
`dotnet/`. The managed projects are `dotnet/Runtime`, `dotnet/FSharp`,
`dotnet/Execution`, and `dotnet/Client`. Subsequent native-platform development
stays in this repository.

The imported components retain their own existing license, notice and
source-provenance records. The backend retains its upstream license and Git
history. This record does not assert new redistribution rights or that a runtime
artifact was produced.
