# Working on Convex.Runtime

This is part of the independently owned native Convex platform. Use the root `Convex.slnx`, `global.json`, and central package policy. Application projects consume released packages and are not a source prerequisite. Prefer idiomatic functional F# and preserve active transaction/security semantics. Do not add another product's project references or a Fable route. Do not run builds, tests, verification or deployments unless the current user scope requests them.
