# Convex.Runtime

Language-neutral .NET invocation and declaration contracts for the native Convex backend. This layer must not depend on application policy or the F# frontend. The native platform repository owns its source and version; products consume its NuGet package.

Open `../../Convex.slnx`. See `../README.md` for runtime and package composition. Exercised release checks are recorded in [implementation status](../IMPLEMENTATION_STATUS.md). This page describes the contract, not those checks.
